# nuavu-today

누아브 자사몰 "실시간 당일발송 확인" 위젯용 데이터.

- `p/<카페24상품코드>.json` — 옵션별 상태 (`1` 오늘출발 / `0` 일반배송 / `-1` 품절), `u` = 재고 기준 시각
- `index.json` — 마지막 갱신 요약
- `map.json` — 카페24 상품코드 ↔ 상품명·옵션 매핑 (카페24 상품 엑셀에서 생성)
- `build_today.py` — 이지어드민 현재고조회 xls → 위 파일 생성

재고 원본은 이지어드민(정상재고 − 송장 − 접수 > 0 → 오늘출발, 정상재고 ≥ 9999 → 오늘출발). 30분 주기 갱신.
